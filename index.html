VSCode Markdown Styles — Sample

This page exercises every style defined in vscode-markdown-styles.css. It uses a warm parchment background, an ink-blue accent, and a warm-red border to mark section headings.

To use this, add the following to vs code config file settings.json

"markdown.styles": ["https://my-public-files.flyingwhalelab.workers.dev/vscode-markdown-styles.css"]

Typography

Body copy is set in Charter with a fallback to Georgia and Palatino. The line-height is comfortable for reading at 16px. Italic-styled emphasis is rendered upright in a muted olive — the stylesheet deliberately avoids true italics.

Links such as this inline link use the ink-blue accent with a soft underline that lifts on hover.

A Smaller Subhead

Subheads share the same warm-red rule as h2 but at a lighter weight and a softer text color.

Blockquote

"Simplicity is the ultimate sophistication." A blockquote uses an ink-blue rule on the left, olive text, and a transparent background.

Lists

Unordered list:

  • Parchment-toned page background
  • Ivory surface for cards and code blocks
  • Warm-red accent on section rules

Ordered list:

  1. Set the document language and charset
  2. Link the stylesheet in the <head>
  3. Write semantic markdown-shaped HTML

Inline Code & Code Block

Inline snippets like const greeting = "hello" sit on a pale-blue chip with a warm-red glyph color.

function greet(name) {
  const message = `Hello, ${name}!`;
  console.log(message);
  return message;
}

greet("world");
